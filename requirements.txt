# OCR is OPTIONAL and deliberately NOT installed here.
#
# Scanned/image-only results tables need an OCR engine. PaddlePaddle 3.3.1 and
# PaddleOCR 3.7.0 DO install cleanly on Python 3.12 (the version runtime.txt
# pins) -- an earlier note in this file claiming otherwise was wrong. The
# obstacle is size: roughly 1.4 GB once the model files download on first use.
#
# It is kept out of this file because a failed Community Cloud build takes the
# WHOLE app down, including the annual/Excel workflow, which needs no OCR.
#
# To enable it, see requirements-ocr.txt (pins + measured footprint) and
# docs/quarterly_ocr_deployment.md. If the local engine does not fit, set
# FUNDACHECK_OCR_PROVIDER=remote and FUNDACHECK_OCR_URL instead -- no parser
# code changes.
#
# core/quarterly_ocr.py imports every engine lazily and falls back to a null
# provider, so with none installed the app runs normally and rasterised cells
# are reported unavailable ("--") rather than guessed.
