# Core application
# Version FLOORS (>=) rather than exact pins: Streamlit Community Cloud currently
# builds on Python 3.14, and the old exact pins (numpy 1.26.4, pandas 2.2.2,
# streamlit 1.38.0) have no 3.14 wheels, which made the install fail / build from
# source. Floors let the resolver pick 3.14-compatible wheels.
streamlit>=1.40
pandas>=2.2
numpy>=1.26
plotly>=5.24
openpyxl>=3.1
requests>=2.32
beautifulsoup4>=4.12
fpdf2>=2.8

# OCR is OPTIONAL and deliberately NOT installed on Streamlit Community Cloud:
#   * PaddleOCR PP-StructureV3 (primary) — `paddlepaddle` has no wheel for the
#     Cloud's Python (3.14) and is too heavy for its image/memory limits, so it
#     is omitted here. Install `paddlepaddle` + `paddleocr` in an environment
#     that can host them to enable OCR of rasterised / scanned tables.
#   * Surya (secondary cross-check) — Torch-based, multi-GB; install `surya-ocr`
#     explicitly where it fits.
# core/quarterly_pdf.py imports these lazily and degrades gracefully: native-text
# filings work fully, and rasterised/scanned cells are marked "unavailable"
# (never fabricated) when no OCR engine is present.
